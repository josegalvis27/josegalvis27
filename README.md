### 👋 Sobre mí

Soy **Ingeniero en Informática** de Caracas, Venezuela 🇻🇪. Lidero la tecnología de **[Coco Wallet](https://cocowallet.app)**, una wallet self-custodial en dólares con rampas fiat en 9 países de América y Europa, y soy co-founder de **Staff On**, un marketplace de talento temporal.

- 🔐 Migré **3.500+ usuarios** de frase semilla a **MPC/TSS** sin pérdida de fondos
- ⚡ Transacciones **sin gas** con account abstraction (**ERC-4337**) en Polygon, Optimism, Base, BNB y Celo
- 📈 Crecimiento **×4** en operaciones mensuales mientras el costo de RPC bajaba **75 %**
- 💳 Integré **10+ rieles de pago y KYC**: Bridge, Ripio, Pago Móvil, Bizum, Zelle, Stripe, Ramp, Sumsub
- 🤖 Diseño **oficinas de agentes de IA** con Claude Code: los agentes proponen, las personas aprueban

### ⚙️ CI/CD · GitHub Actions

Pipelines que creé para Coco Wallet:

| Workflow | Qué hace |
|---|---|
| 📦 **Build & Notify QA** | En cada merge a `develop` calcula el build con la API de App Store Connect, compila APK y IPA firmados y avisa a QA |
| 🤖 **Claude Fix QA Bug** | QA comenta en un issue → Claude Code arregla el bug en la rama correcta, abre el PR y lo enlaza al issue |
| 🖼️ **Update Goldens** | Regenera los golden tests en Linux igual que CI y los commitea a la rama del PR |
| 🔑 **Check iOS Credentials** | Cada lunes revisa el `.p12` y el provisioning profile y avisa 30 días antes de que venzan |
