### 👋 Sobre mí

Soy **Ingeniero en Informática** de Caracas, Venezuela 🇻🇪. Desde 2022 soy **CTO de [Coco Wallet](https://cocowallet.app) y Coco Mercado**, una wallet self-custodial en dólares con rampas fiat en 9 países de América y Europa, y soy **co-founder de Staff On**, un marketplace de talento temporal para eventos.

### 🎯 Casos destacados

| | Problema → Solución → Resultado |
|---|---|
| 🔐 **MPC sin perder fondos** | La wallet dependía de frases semilla → integré MPC/TSS (Particle) en la app Flutter y lideré la migración → **3.500+ usuarios con saldo migrados, cero pérdida de fondos** |
| ⚡ **Envíos que no fallan** | Una parte de los envíos ERC-4337 fallaba → rastreé la causa raíz (nonce de UserOps) y la llevé al cliente → **−83 % de errores de envío** y **−64 % de gas** por transacción |
| 💸 **Infraestructura más barata** | US$ 80/día en RPC → diagnostiqué un monitor de depósitos mal calibrado → **−75 % de costo (~US$ 22K al año)** mientras las operaciones crecían ×4 |
| 💳 **10+ rieles de pago** | Bridge, Ripio, Pago Móvil, Bizum, Zelle, PayPal, Stripe, Ramp y KYC con Sumsub, en 9 mercados |

### ⚙️ CI/CD · GitHub Actions

Pipelines que creé para Coco Wallet:

| Workflow | Qué hace |
|---|---|
| 📦 **Build & Notify QA** | En cada merge a `develop` calcula el build con la API de App Store Connect, compila APK y IPA firmados y avisa a QA |
| 🤖 **Claude Fix QA Bug** | QA comenta en un issue → Claude Code arregla el bug en la rama correcta, abre el PR y lo enlaza al issue |
| 🖼️ **Update Goldens** | Regenera los golden tests en Linux igual que CI y los commitea a la rama del PR |
| 🔑 **Check iOS Credentials** | Cada lunes revisa el `.p12` y el provisioning profile y avisa 30 días antes de que venzan |
